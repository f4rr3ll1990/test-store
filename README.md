# СКЛАД-МАГАЗИН — оптово-роздрібний

Одностраничная верстка магазина оптово-розничной торговли по референсу `image_0.png`.
Чистые HTML/CSS/JS без сборки — откройте `index.html` в браузере.

## Файлы

| Файл | Назначение |
|---|---|
| `index.html` | Разметка + SVG-спрайт (иконки и иллюстрации товаров) |
| `style.css` | Дизайн-система в `:root` + секции + адаптив |
| `app.js` | Слайдер, табы, карусель товаров, корзина, тосты |

## Порядок блоков

Верхняя панель → Шапка → Герой-слайдер → Категории → Спецпредложения →
Ценности → Хит продаж → Бренды / Про нас / Статистика → Футер.

## Дизайн-система

Все токены — в `:root` (`style.css`). Меняются в одном месте.

```
--accent      #FFC700   CTA, акценты, иконки
--accent-600  #FFB800   hover
--danger      #E53935   акции, зачёркнутые цены, стикеры
--ink         #1A1A1A   основной текст
--surface     #F4F5F7   подложки карточек
--container   1232px    12-колоночная сетка, gutter 24px
```

Шрифт — Inter (Google Fonts). Скругления 8–12px, у героя 20px.

## Изображения

Все картинки — **inline SVG-плейсхолдеры** в спрайте `<svg class="sprite">`
в начале `index.html`. Ничего не грузится извне, страница работает офлайн.

Чтобы подставить реальные фото, замените
`<svg class="ill" viewBox="..."><use href="#p-fridge"/></svg>`
на `<img src="assets/fridge.jpg" alt="...">` — CSS-классы (`.product-art`,
`.cat-art`, `.promo-art`) уже задают размеры и hover-анимации.

> Логотипы брендов — текстовые заглушки, а не настоящие товарные знаки.
> При публикации замените их на официальные логотипы с разрешения владельцев.

## Данные товаров

Карточки рендерятся из объекта `CATALOG` в `app.js` (три вкладки:
`hit` / `new` / `sale`). Формат позиции:

```js
{ tag: 'hit', art: 'p-fridge', name: '…', now: 18999, was: 21999, rate: 4.8 }
```

`tag` → цвет стикера (`hit` красный, `new` зелёный, `sale` синий),
`art` → id символа в спрайте.

## Интерактив

- **Слайдер героя** — автопрокрутка 6 с, стрелки, пагинация `01/02/03`,
  свайп на тач-экранах, стрелки клавиатуры; пауза при наведении и при
  уходе вкладки в фон.
- **Табы** — «Хіт продажів» / «Новинки» / «Акційні товари» с fade-переходом.
- **Стрелки ряда товаров** — циклически прокручивают список.
- **Корзина и избранное** — счётчик в шапке, тосты; обработчики делегированы
  на `document`, поэтому переживают перерисовку карточек.

Кнопки без реальной логики (поиск, каталог, обратный звонок, мобильное меню)
показывают тост-заглушку.

## Адаптив

| Ширина | Категории | Товары | Ключевые изменения |
|---|---|---|---|
| ≥1180px | 7 в ряд | 6 в ряд | карточка преимуществ поверх слайда |
| 1024–1180 | 4 | 4 | карточка преимуществ уходит под слайд |
| 900–1024 | 3 | 4 | шапка сжимается: подписи скрыты |
| 768–900 | 3 | 4 | промо-карточки в колонку |
| <768 | 2 | 2 | верхняя панель скрыта, поиск во вторую строку |

Учитывается `prefers-reduced-motion`.

## Расхождения с текстовым ТЗ

Приоритет отдан референсу:

- категорий в ряду **7** (6 + «Всі товари»), в ТЗ было «5 + 1»;
- товаров в ряду **6**, в ТЗ было 5;
- добавлен блок «Бренди / Про нас / Статистика» перед футером — он есть
  на референсе, но не описан в ТЗ;
- футер на референсе обрезан, поэтому собран по п. 9 ТЗ.
